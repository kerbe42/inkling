# Contributing

Thanks for your interest in Inkling. Bug reports are welcome: open an issue with the bug report form, and never
include API keys, app passwords or tokens. Ideas and suggested changes are welcome as issues too.

The source is open (GPL-3.0) so you can read it, build it and check the official releases against it, but the project
doesn't take pull requests: they're closed automatically with a pointer to the issues. You're free to fork it under the
GPL; if you publish a fork, please give it its own name, icon and signing key (see [BUILDING.md](BUILDING.md)).
Inkling is published by JSSL.
